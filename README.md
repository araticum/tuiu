# Tuiú

SaaS de gestão de transferências da União (Transferegov.br) para quem **recebe**: prefeituras, consórcios públicos e OSCs.

Espelho gerencial da carteira de instrumentos + motor de prazos com base legal + monitor CAUC/certidões + relatório de gestão de emendas Pix + documentos assinados ICP-Brasil (A1). Alimentado pelas APIs e CSVs públicos oficiais (dados D-1). **Não transaciona** no Transferegov — prepara, vigia e documenta; o protocolo final é do usuário na plataforma oficial.

- Plano fundador: [`docs/plano-transferegov-saas.md`](docs/plano-transferegov-saas.md) (pesquisa verificada em 17/07/2026 + arquitetura + roadmap F0–F6)
- Codinome: **Tuiú** (tuiuiú, o jaburu do Pantanal) — aprovado em 17/07/2026
- Peças doadoras: monorepo `araticum/oasis.v2` (Sargaço, candeia-a1, Seriema, pdf-render, compêndio IA, doc-extractor)
- Operação no araticum (containers, deploy, cadeia diária, sonda): [`ops/README.md`](ops/README.md)
